### Installation
```
$ activate
$ pip install -r requirements.txt
$ pip install torch --index-url https://download.pytorch.org/whl/rocm6.0
```

### Run
```
$ activate
$ HSA_OVERRIDE_GFX_VERSION=10.3.0 python main.py cmd [flags]
```
